Reflection
Why should developers use feature branches?
Because developers can develop different features simultaneously without causing conflicts in the main branch.
What caused the merge conflict?
If two developers change the same line (for example in README.md), Git does not know which version of the line to choose.
How did GitHub help you resolve it?
GitHub clearly shows the conflicting changes and lets you choose which version to keep (or combine both) before completing the merge.
Why are pull requests useful in teams?
Team members can review each other's code, give feedback, and either approve or request changes before merging into main.
